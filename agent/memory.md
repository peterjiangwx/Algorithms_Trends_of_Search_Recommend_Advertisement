**一句话经验：好的 memory 系统不是"让 agent 记住一切"，而是 "让正确的信息在正确的时机被正确的方式带回 context" —— 分层（working / episodic / semantic / procedural）、结构化（schema
  而非自由文本）、克制写入（反思驱动而非无脑提取）、混合检索（关键词+向量+rerank）、主动淘汰（时间+冲突+置信度）、隐私合规（隔离+脱敏+审计）。Agent 的"长期能力"上限，往往不在模型参数，而在 memory 系统的工程深度**
