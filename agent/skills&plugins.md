**一句话经验：好的 skill / plugin 系统不是"把功能堆成一个市场"，而是 "让能力以可发现、可治理、可演进、可信任的方式被按需调用" —— 渐进加载防膨胀、描述工程定触发、文件系统保可移植、版本依赖管演进、沙箱权限护安全、评测回归保质量、registry治理保生态。Agent 的能力上限不在工具数量，而在 skill 系统的工程深度——这跟"应用商店之于操作系统"是同一回事，agent 时代的"应用层标准"正在 2025–2026 这个窗口期成型**
