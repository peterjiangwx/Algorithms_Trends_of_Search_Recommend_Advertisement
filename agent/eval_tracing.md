**一句话经验：好的 evaluation & observability 系统不是"加几个仪表盘"，而是 "让每一次决策、每一次调用、每一次失败都能被精确定位、被严谨评判、被持续改进" —— 标准化 trace（OTel）、分层评测（金字塔）、多维指标（quality / cost / latency /
  safety）、双闭环（离线回归 + 在线监控）、数据飞轮（生产 → 评测集 → 修复 → 验证）、合规底座（脱敏 / 审计 / 隔离）。Agent 系统的迭代速度，等于它的可观测速度——看不见的东西改不动；改不动的东西不会变好。2026 年区分"玩具 agent"和"生产
  agent"的最硬指标，不是模型能力，是评测与可观测的工程深度**
